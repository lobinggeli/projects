# McKinsey Pyramid Principle

Use this framework to structure communication for maximum clarity and impact. Start with the answer, then provide supporting arguments in a logical hierarchy.

## Core Concept

**Lead with the answer, then explain.** The pyramid structure presents the main conclusion first, supported by key arguments, each backed by detailed evidence.

```
           [Main Point/Answer]
                  ↓
    [Key Argument 1] [Key Argument 2] [Key Argument 3]
          ↓               ↓               ↓
    [Supporting     [Supporting     [Supporting
     Evidence]       Evidence]       Evidence]
```

## The SCQA Framework (Situation-Complication-Question-Answer)

Use this to introduce your pyramid:

1. **Situation**: Establish the context (what everyone agrees on)
2. **Complication**: Introduce the problem or change
3. **Question**: The question raised by the complication
4. **Answer**: Your recommendation (top of the pyramid)

## Grouping Logic (MECE Principle)

Arguments must be **MECE**: Mutually Exclusive, Collectively Exhaustive
- **Mutually Exclusive**: No overlaps between categories
- **Collectively Exhaustive**: All relevant points covered

## Ordering Logic

Choose one ordering principle per level:
- **Time/Sequence**: First, second, third...
- **Structure**: Geographic, organizational, component-based
- **Importance/Priority**: Most to least important
- **Deductive**: Major premise → Minor premise → Conclusion
- **Inductive**: Similar facts → Pattern → Conclusion

## When to Apply
- Executive presentations and memos
- Email communication
- Meeting preparation
- Report writing
- Recommendation documents
- Stakeholder updates

## Key Rules

1. **Ideas at any level must summarize the ideas below**
2. **Ideas in each grouping must be the same kind of idea**
3. **Ideas in each grouping must be logically ordered**
4. **Answer the question "Why?" or "How?" at each level**

## Analysis Template
```
## Communication Structure: [Topic]

### SCQA Introduction
- **Situation**: [Context that audience agrees with]
- **Complication**: [The problem or change]
- **Question**: [What needs to be answered]
- **Answer**: [Your main recommendation]

### Pyramid Structure

**Main Message**: [Single governing thought]

**Key Arguments** (MECE):
1. [Argument 1]
   - Supporting point 1a
   - Supporting point 1b
   - Supporting point 1c

2. [Argument 2]
   - Supporting point 2a
   - Supporting point 2b
   - Supporting point 2c

3. [Argument 3]
   - Supporting point 3a
   - Supporting point 3b
   - Supporting point 3c

### Executive Summary
[2-3 sentence summary following the pyramid top-down]
```

## Quick Reference: The 30-Second Test

Your communication passes if someone can understand:
- What you're recommending (in 30 seconds)
- Why they should agree (in 2 minutes)
- The supporting details (if they want to dig deeper)
